# Nasugbu barangay reference boundaries

`nasugbu-barangays.geojson` is the unmodified full-resolution 2011 Nasugbu barangay collection (42 features) from James Faeldon's Philippines JSON Maps, pinned at commit `8eeead560246863c8c820c31ca6fbca81a279477`.

Source: https://github.com/faeldon/philippines-json-maps/blob/8eeead560246863c8c820c31ca6fbca81a279477/2011/geojson/barangays/barangays-municity-171-nasugbu.json

MIT license retained in `LICENSE`. This is a reference map, not a certified district jurisdiction or survey. The document prints the vintage; no hectares are calculated from these polygons. Runtime rendering uses no network, tiles, API key or browser. The source digest is sealed with content so changes require a new version.
