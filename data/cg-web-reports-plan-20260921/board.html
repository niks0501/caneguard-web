Report documents

One report, two formats

The authenticated HTML preview and PDF download use the same report builder and Blade document. The preview route and API contracts remain unchanged.

  • Preview: GET /api/v1/reports/documents/report
  • Download: GET /api/v1/reports/documents/report/pdf
  • PDF output: Dompdf through spatie/laravel-pdf.

Portable rendering

PDF generation runs in PHP without requiring an external renderer executable or a machine-specific binary path. The report template uses table-based layout and CSS supported by Dompdf.
